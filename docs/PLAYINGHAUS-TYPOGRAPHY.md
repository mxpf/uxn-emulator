# Playinghaus typography

Selected by the user: **Orbitron**, replacing the earlier Square 721 selection.
Use regular weight for interface copy and bold for headings. Buttons inherit
the same family. The illustrated Playinghaus logo and cartridge art are unchanged.

The unmodified Latin variable WOFF2 (weights 400–900) is self-hosted at
`web/fonts/orbitron-latin.woff2`. All four pages load `web/fonts.css`; the shared
`web-fonts` build target includes the font and its SIL Open Font License.
There are no runtime requests to Google Fonts. System fallbacks cover symbols
and remain available while the font loads.
